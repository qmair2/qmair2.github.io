Procedural Maze Game on Custom Processor

A dungeon-crawler maze game running on a custom 32-bit pipelined processor implemented on an FPGA.

Verilog MIPS Assembly VGA FPGA

Abstract

This project involved designing and implementing a custom 32-bit pipelined processor on an FPGA, then using it to run a real-time procedural maze game displayed over VGA.

The system combined processor design, memory-mapped I/O, graphics output, assembly programming, and hardware debugging into a complete working platform.

System Architecture

The system consists of a custom CPU, instruction memory, data memory, VGA controller, input handling, and game logic written in assembly.

  • Five-stage instruction pipeline
  • Hazard detection and forwarding
  • Memory-mapped graphics interface
  • VGA timing and pixel generation

Technical Deep Dive

Processor Design

Designed the datapath, control logic, pipeline registers, and forwarding unit in Verilog.

Verification

Tested individual modules with simulation and debugged timing behavior using waveform analysis.

Graphics

Built a VGA controller and memory-mapped display system for real-time game rendering.

Challenges & Debugging

One major challenge was handling pipeline hazards that caused incorrect game behavior. I debugged the issue using simulation waveforms and resolved it by improving the forwarding and stall logic.
